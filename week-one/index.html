The one thing to add · 5 minutes in Lovable

Three fields, and the portal measures itself

Right now a commission record has the closing date and the money. It doesn't know when the check arrived or when the agent got paid. Add these and "days to paid" shows up on its own, every month, no spreadsheet.

FieldTypeWhere it shows
Check receivedcheck_received_dateDate, optionalAdd Commission form, Commission History column
Agent paidagent_paid_dateDate, optionalSame. Blank means not paid yet.
Payout methodpayout_methodDropdown: Fruitland Tuesday, ICCU deposit, Mailed check, ElectronicSame
Days to paidcomputedAgent paid minus check receivedColumn on Commission History. Average on the admin Performance tab, overall and by method.
Paste into LovableOn the commission record (the Add Commission form and the Commission History table on each agent page), add three optional fields: "Check received" (date), "Agent paid" (date), and "Payout method" (select: Fruitland Tuesday, ICCU deposit, Mailed check, Electronic). Show all three as columns in Commission History. Add a computed column "Days to paid" = Agent paid minus Check received, blank if either date is missing. On the admin Performance tab, add a card "Check to paid" showing the average Days to paid for the last 30 days, plus the average by payout method. Existing records stay unchanged with the new fields blank. Admin can edit these fields on any record.
